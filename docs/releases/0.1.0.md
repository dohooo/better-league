The first Better League release for macOS 26 and later.

## Included

- A compact native Liquid Glass panel with one cursor-recovery switch.
- Menu bar controls to enable recovery, show or hide the panel, and quit.
- No Dock icon, saved switch state, and Accessibility permission guidance.
- Automatic recovery when the League of Legends cursor changes into the system arrow.
- A universal app for Apple silicon and Intel Macs.

## Install

Open the DMG, drag Better League into Applications, and launch it. Turn on Cursor recovery and allow Accessibility when prompted. Stop any existing `lol` command-line guard first.

## Known limitations

Recovery requires attack-move targeting on the physical A key. It can type `a` into chat or shop search. Cursor detection uses private macOS APIs and a full-screen width heuristic; other display configurations and in-game recovery still need broader testing.
