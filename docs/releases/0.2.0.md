Better League 0.2.0 adds a second switch for players on Wi-Fi.

## New

- **Low-latency Wi-Fi.** macOS shares the Wi-Fi radio with AWDL, the peer-to-peer link behind AirDrop and Handoff, and with Wi-Fi Aware. While those interfaces are up, the radio leaves your access point's channel about every half second, which shows up as periodic ping spikes in a match. With the switch on, Better League lowers `awdl0` and `nan0` when a match starts, lowers them again if macOS brings them back, and raises the ones it lowered when the match ends, when the switch is turned off, or when the app quits.
- A **Low-Latency Wi-Fi** item in the menu bar menu. The switch state is saved between launches.
- Wi-Fi guard logs in `~/Library/Logs/better-league/wifi.log`.

## Setup

The first time the switch is turned on, enter an administrator password once. The app writes `/etc/sudoers.d/better-league`, a rule that only lets your account run `ifconfig awdl0|nan0 up|down` without a password. Remove it with `sudo rm /etc/sudoers.d/better-league`.

## Install

Open the DMG, drag Better League into Applications, and launch it. Cursor recovery still needs Accessibility access; Low-latency Wi-Fi does not.

## Known limitations

AirDrop, Handoff, Universal Control, and Sidecar are unavailable while a match runs with Low-latency Wi-Fi on. The app checks for the League game client every 2 seconds, so the radio is lowered a moment after the match client starts. Cursor recovery limitations from 0.1.0 still apply.
